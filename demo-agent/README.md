# Demo Agent — Planned

The future synthetic demo runtime will expose a minimal Payment Operations Agent with:

- governed RAG over synthetic runbooks;
- read-only payment status tool;
- Kafka/MQ history adapter or simulator;
- OpenShift/metrics read tool;
- one bounded remediation tool;
- deterministic policy enforcement;
- separate human approval path;
- audit/correlation.

The demo agent exists only to exercise security controls. It is not intended to duplicate the full Wero or TradeOps runtime.
